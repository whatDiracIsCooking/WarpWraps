# coverage_decisions.json — the curated half of the shared-surface spec

`devtools/coverage_decisions.json` is the **hand-written** companion to the
machine-generated `vendor/*.json` manifests. The manifests answer *what the two
backends declare* (a diff over harvested data); this file answers the two things
a diff cannot compute and a human must decide:

1. **each module's contract class** — is a shared name the module skips a
   *defect* or an *unused vendor symbol*? — and
2. **the shared names a whole-surface module deliberately does not wrap**, with
   the rationale, so `--coverage` applies the decision instead of a reader
   remembering it.

It is the *exception list*, not an enumeration: ~10,700 exports stay derived in
the manifests, and only the dozen-odd human judgements live here. Never grow it
into a per-symbol inventory.

`devtools/header_intersection.py --module <name>` reads it (see that script's
header for how the verdict is applied). It needs **no SDK** — pure data.

## Schema

```jsonc
{
  "contract_classes": { "<class>": "<what the class means>" },
  "modules": {
    "<module>": {
      "contract": "whole-surface" | "curated-subset",
      "cuda": ["<pin>/<lib>.json", ...],   // manifests, relative to vendor/
      "hip":  ["<pin>/<lib>.json", ...],
      "src":  ["src/....cppm", ...],        // the module source --coverage scans
      "omissions": [
        {
          "key":  "<short label>",
          "cuda": "<name>|<name>|<name*>" | null,  // literal vendor names,
          "hip":  "<name>|..."            | null,  // '|'-joined, '*' = prefix
          "why":  "<the rationale, transcribed from the tree>",
          "source": "<where the rationale is documented>"
        }
      ]
    }
  }
}
```

### The two contract classes

- **whole-surface** (`rand`, `fft`, `tx`) — promises the full intersection
  (`WWR_FUNCTION(gpu, cu, hip)` spells both names). An undocumented gap **fails**
  `--coverage`; a gap listed in `omissions` **passes** (a named, justified skip).
- **curated-subset** (`blas`, `solver`, `sparse`, `runtime_api`) — wraps only
  what the layer above uses, so its gaps are a discovery menu: **reported, never
  failed**. Completeness for these is enforced by the compiler,
  `test/shared/alias_coverage.py`, and the dispatch tables.

### An `omissions` entry

`cuda` / `hip` hold the **literal vendor identifiers**, `|`-joined; a trailing
`*` is a prefix wildcard (`cusolverMg*`); `null` means the backend has no such
name. An entry matches a missing intersection item when any of its names matches
one of that item's actual cuda/hip names. `why` is transcribed from the tree —
this file is the *enforced* home for facts (version-stamped link notes, "no ROCm
counterpart") that a source header must not carry, per the docstyle convention;
`source` cites where each rationale is documented.

## Regenerating

There is nothing to regenerate — this file is decisions, not harvest. Edit it by
hand when a contract class changes or a documented omission is added or removed.
The manifests it sits on are regenerated by `devtools/vendor_manifests.sh`.
